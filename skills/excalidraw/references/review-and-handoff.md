# Review and handoff

Inspect the **rendered** diagram at its initial viewport and final overview.
Coordinates and a plausible link are insufficient evidence.

1. **Meaning:** Does it state the lesson's claim? Check arrow directions,
   labels, boundaries, state order, units, and color meanings against the text
   and subject guide.
2. **Legibility:** At normal inline size, check every label for overlap,
   clipping, ambiguous crossings, and tiny annotations. Inspect the overview
   and a narrow display when the viewer will show one.
3. **Completeness:** Read the returned scene data and assert every expected
   label verbatim. Read the backing scene from the handoff link and check the
   same labels there. A short link key may be valid; its length proves nothing.
4. **Teaching:** Introduce the view with its question, explain the smallest
   path through it, and ask for a prediction under a changed input or
   boundary condition. Opening a view is not evidence of understanding.
5. **Publication:** Return an inspected local export in a manifest-supported
   format. Discover export support from the actual tools; do not invent an
   export command. If only a view exists, give the coordinator its working
   link and state that a publishable artifact is still needed.

Reject a scene whose link lacks expected content or whose export has not been
visually checked. Tell the coordinator which check failed. Register an
artifact as `ready` only after its visual evidence is available and inspected.
