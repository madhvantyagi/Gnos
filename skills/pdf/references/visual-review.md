# Inspect the rendered lesson

Read the PDF at ordinary size before zooming in. If a page needs zoom to be
usable, fix the typography or split the material.

- Each heading has meaningful content beneath it on the same page.
- Equations have no missing symbols; subscripts and fraction bars remain sharp.
- Figures retain aspect ratio, labels, units, and their caption.
- Tables wrap within the margins and repeat headers when split.
- No clipped code, orphaned caption, text collisions, or unintended blank pages.
- Page numbers and the running title do not compete with body content.
- The worked example and exercise test the stated outcome; solutions are placed
  where the learner expects them, not accidentally exposed beside a diagnostic.
- Source credit distinguishes an original drawing from a reproduced figure.

After a change, render again. The final PDF must be the file actually inspected,
not an earlier version with the same name.
